模块由三个协作文件组成：
- `src/main.js` 是 Vue CLI 的入口，负责引入 ElementUI（英文 locale）、全局样式、icons、store、router 以及本模块的 `permission.js`，并在生产环境通过 `require('../mock')` 动态加载 MockJs；最终 `new Vue({ router, store, render: h => h(App) })` 挂载到 `#app`。
- `src/App.vue` 是最顶层容器，仅渲染 `<router-view/>`，作为所有子路由的占位符。
- `src/permission.js` 在导入时即注册 `router.beforeEach` / `router.afterEach` 全局守卫：未登录且非白名单 `/login` 则重定向至登录页；已登录但缺少用户信息时调用 `store.dispatch('user/getInfo')` 拉取；成功后放行，失败则 `resetToken` 并提示错误；同时通过 `getPageTitle` 设置 `document.title`，并用 NProgress 包裹导航生命周期。
依赖方向单向：main → App + permission；permission → router/store/utils/auth，不反向依赖业务模块。
