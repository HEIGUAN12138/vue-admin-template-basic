应用以 src/main.js 为唯一入口，集中注册 ElementUI、全局样式、icons 插件并注入 router 与 store；src/permission.js 在启动时挂载 router.beforeEach/afterEach，作为所有子模块共享的全局鉴权与进度条钩子，统一拦截未登录跳转、白名单放行以及登录后拉取用户信息。
- 数据层：store/modules 下的 app/settings/user 三个模块由 store/index.js 聚合，被 permission、layout、views 共同消费。
- 表现层：layout/ 提供 Sidebar/Navbar/AppMain 等壳组件，router/index.js 将 views/ 下的业务页面按嵌套结构挂载到 layout 中。
- 交互层：api/table.js、api/user.js 经 utils/request.js（封装 axios）调用后端，权限判断依赖 utils/auth.js 中的 token 存取。
- 配置层：settings.js 集中导出 title、fixedHeader、sidebarLogo 等运行时开关，被 get-page-title、layout 等读取。
- 资源层：assets/404_images、icons/svg 配合 components/SvgIcon 与 icons/index.js 实现 SVG 图标按需注册。
