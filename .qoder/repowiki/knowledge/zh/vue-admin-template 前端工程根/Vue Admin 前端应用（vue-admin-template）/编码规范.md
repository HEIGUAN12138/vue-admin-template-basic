- 跨模块共享状态统一放在 store/modules 下，并通过 store/getters.js 暴露只读属性供组件与权限逻辑读取。
- 对外 HTTP 请求集中在 api/*.js 中定义，统一通过 utils/request.js 发起，避免在组件内直接调用 axios。
- 路由元信息 meta.title 经由 utils/get-page-title.js 处理，并在 permission.js 的 beforeEach 中同步设置 document.title。
- 静态资源与 SVG 图标分别放入 assets/ 与 icons/svg/，并通过 @/icons 入口统一注册后在组件中以 <svg-icon> 使用。
