测试按源码目录镜像组织：`components/` 下对应 `src/components` 中的 Vue 单文件组件，`utils/` 下对应 `src/utils` 中的纯函数模块；每个被测源文件配一个同名 `.spec.js`。
- 组件测试通过 `@vue/test-utils` 的 `mount`/`shallowMount` 挂载实例，使用 `createLocalVue` + `localVue.use()` 注入 `VueRouter`、`ElementUI` 等依赖，并构造 `routes` 数组驱动路由场景（如 Breadcrumb 的多级菜单）。
- 工具函数测试直接 import 源码导出函数，以 `describe` + `it` 断言返回值。
- 根目录 `.eslintrc.js` 仅开启 `jest: true` 环境，表明测试运行器为 Jest，ESLint 规则在测试目录下独立于项目根配置。
