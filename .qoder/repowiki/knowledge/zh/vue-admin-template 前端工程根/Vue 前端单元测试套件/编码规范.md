- 每个被测源文件在同级目录下提供同名 `.spec.js` 作为其单元测试入口。
- 组件测试统一通过 `@vue/test-utils` 的 `mount` 或 `shallowMount` 创建 wrapper，再使用 `wrapper.find` / `wrapper.findAll` 选择 DOM 节点进行断言。
- 需要外部依赖（router、UI 库）时，先 `createLocalVue()` 再 `localVue.use(...)` 注入，避免污染全局 Vue 实例。
- 测试用例以 `describe` 包裹模块名、`it` 描述具体行为，断言集中在 `expect(...).toBe(...)` 形式中。
