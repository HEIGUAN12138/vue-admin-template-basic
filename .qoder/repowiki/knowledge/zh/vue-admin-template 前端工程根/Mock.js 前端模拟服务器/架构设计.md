模块以 `index.js` 为聚合入口：合并 `user.js` 与 `table.js` 导出的路由数组，并通过 `mockXHR()` 重写 `Mock.XHR.prototype.send`，将浏览器侧的 XHR 请求拦截到本地 Mock；同时导出 `mocks` 供外部使用。

- `mock-server.js` 是独立的 Express 应用启动器：通过 `body-parser` 解析请求体，调用 `registerRoutes()` 把每个 mock 条目包装成 Express 中间件（`responseFake`），挂载到传入的 app 上，并用 `chokidar` 监听 `mock/` 目录变化，在文件变更时从 `app._router.stack` 中移除旧路由、清空 `require.cache` 后重新注册，实现热重载。
- `user.js`、`table.js` 是业务路由定义层，统一导出形如 `{ url, type, response }` 的数组，`response` 可接收 Express 风格的 `(req, res)` 回调或静态对象。
- `utils.js` 提供纯函数 `param2Obj`，用于在浏览器模式中将 URL query 字符串解析为对象。

依赖方向：`mock-server.js` → `index.js` → (`user.js`, `table.js`)，`utils.js` 被 `index.js` 单独引用；业务路由文件之间无相互依赖。
