- 每个业务域（user、table）以模块形式导出一个路由数组，元素统一包含 `url`、`type`、`response` 三个字段。
- `response` 处理器采用 Express 风格回调 `(req, res) => { code, data }` 返回 JSON，错误路径返回非 20000 的 `code` 与 `message`。
- URL 匹配使用正则表达式（如 `/vue-admin-template/user/info\.*`），由 `mock-server.js` 在注册时包裹 `process.env.VUE_APP_BASE_API` 前缀后再转 RegExp。
- 模拟数据通过 `Mock.mock({...})` 的数据模板语法生成，再在路由处理器中以普通 JS 对象形式消费。
